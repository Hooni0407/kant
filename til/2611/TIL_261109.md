## 2. 오늘 학습 한 내용을 나만의 언어로 정리하기
```
- Class 상속 : 이미 만들어 둔 클래스의 기능을 물려받아 새 클래스를 만드는 것
    - `class Dog(Animal):` 처럼 괄호 안에 부모를 적음
    - 같은 코드를 다시 쓰지 않아도 됨

- 부모 클래스 / 자식 클래스 : 부모: 공통 기능을 가진 클래스 (Animal)
    - 자식: 부모를 물려받고 자기만의 기능을 더한 클래스 (Dog, Cat)
    - 괄호 안의 클래스가 부모, 앞의 클래스가 자식

- 상속 (Interitance) : 자식이 부모의 속성과 메서드를 그대로 쓸 수 있는 성질
    - 예: `dog1.breathe()`는 Dog에 없어도 Animal에서 물려받아 실행됨

- 메소드 오버라이딩 : 부모에 있는 메서드를 자식에서 같은 이름으로 다시 정의해서 동작을 바꾸는 것
    - 예: Animal의 `sound()`가 Cat에서는 "야옹"을 출력
    - 이름은 같게, 내용만 바꿈

- super() : 자식 안에서 부모의 메서드를 대신 실행시키는 것
    - 주로 `super().__init__(...)`으로 부모의 초기화(속성 저장)를 맡김
    - 자식이 `__init__`을 새로 만들면 부모 것은 자동 실행되지 않기 때문에 필요함
  
- __변수 : 변수 이름 앞에 `__`를 붙이면 클래스 바깥에서 직접 접근하지 못하게 숨김 (캡슐화)
    - 완전한 보안은 아니고 "건드리지 마세요"라는 강한 약속
    - 예: `self.__money`

- Getter : 숨겨진 값을 안전하게 꺼내 주는 메서드
    - 예: `get_money()`가 `self.__money`를 return

- Setter : 숨겨진 값을 바꾸는 메서드. 바꾸기 전에 검사 로직을 넣을 수 있음
    - 예: `set_money(amount)`는 0 이상일 때만 값을 바꿈
```
