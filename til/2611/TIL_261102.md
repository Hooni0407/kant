## 5. Python
- ### 산술 연산자의 우선순위
```
1. **   (제곱)
2. *    (곱하기)
3. /    (나누기)
4. //   (몫)
5. %    (나머지)
6. +    (더하기)
7. -    (빼기)
```
- ord() : 모든 1글자 문자에 고정된 고유의 값이 존재하며, 해당 값을 볼 수 있는 함수 (반대함수: chr())

- ### 논리 연산자
    - and : 모든 조건이 충족해야함
    - or : 한가지라도 조건이 충족되면 됨
    - not : 모든 조건이 충족되면 안됨

- ### 문자열
- 사용 예시
    - print("선발 출전: %s, %d" % ("손흥민", 20)) → %s에는 이름, %d에는 정수가 들어감
    - print("선발 출전: [%5d]" % (20)) → %5d는 공백을 줌
    - print("소수점 표기 : %.2f" % 3.141592) →  실수를 소수점 둘째 자리까지 표시 (n을 바꾸면 자릿수가 바뀜, 반올림됨)
    
- format 방식
```
name = "Cake"
price = 6500
qty = 2

format_str = "주문내역: {0} {1}개 -> 총 {2}원".format(name, qty, price)
print(format_str)
```

- f-string 방식
```
format_str = f"주문내역: {name} {qty}개 -> 총 {(price * qty):>10,}원"
print(format_str)
```

### 실습
```
# 가상의 주문 데이터
orders = [
    ("Latte", 5000, 2),
    ("Americano", 3000, 1),
    ("Cake", 6000, 1)
]

print("=" * 32)
print(f"{'메뉴명':<10} {'단가':<8} {'금액':<9}") # ":<숫자 → 꺽새 방향으로 공백을 몇칸 띄울건지"
print("-" * 32)
# print(orders)

# 총 금액
total_amount = 0

for menu, price, qty in orders:
    subtotal = price * qty
    total_amount += subtotal
    print(f"{menu:<10} {price:>8} {subtotal:>9,}원")

print("-" * 32)
print(f"{'합계금액:':<10} {total_amount:>15,}원")
```

- ### 리스트 : [ ] 대괄호를 사용하며, 요소 추가, 수정, 삭제가 가능하다.
    - 메서드 : 각종 자료형에서 그 자료들의 값을 다루는 함수
        - append() : 요소 추가
        - insert() : 원하는 위치에 요소 추가
        - remove() : 원하는 요소 삭제



- ### 튜플 : ( ) 중괄호를 사용하며, 요소 추가, 수정, 삭제가 불가능하다.
```
import sys
print(sys.getsizeof([1, 2, 3]))
print(sys.getsizeof((1, 2, 3))) # 튜플 : 데이터 안정성

※ getsizeof() : 객체 하나가 메모리를 몇 바이트 차지하는지 알려주는 함수
```

### 슬라이싱
numbers = [0, 1, 2, 3, 4, 5]

- numbers[1:4] → 1번부터 4번미만까지 추출
- numbers[::2] → 2칸 간격으로 추출
- numbers[::-1] → 역순으로 추출
- numbers[:3] → 앞에서 3개만 추출
- numbers[3:] → 3번부터 끝까지 추출

```
matrix = [
    [1, 2, 3],
    [4, 5, 6]
]

print (matrix[1])
print (matrix[1][2])
print (len(matrix), len(matrix[0]))
```
