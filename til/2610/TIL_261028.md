### <터미널 명령어>
- git remote -v : 내 컴퓨터(로컬)와 연결된 GitHub 등의 원격 저장소 이름과 주소를 화면에 상세히 보여줌
- git remote add origin (주소) : 내 프로젝트를 연결할 기본 원격 저장소의 주소를 등록하는 명령어 (보통 메인 저장소 이름은 origin이라고 
부름)
- git remote add backup (주소) : 백업용 주소
- git remote remove backup : 백업용 주소 제거
- git clone (주소) : GITHUB에 올려놓았던 폴더를 내 로컬에 다운받는 명령어
- git push -u origin main: 오리진 메인을 기억해서 간편히 사용 가능(?)
- git reset --soft : 해당 고유번호의 커밋으로 되돌아가는 명령어
- git reflog : 브랜치 이동, 커밋, 리셋 등 내가 지금까지 터미널에서 했던 모든 Git 작업 히스토리를 시간순으로 보여줌 커밋을 실수로 날렸거나 과거로 돌아가고 싶을 때, 예전 기록의 고유번호(HEAD@{1} 등)를 찾아내는 용도로 씀
- git reset --hard HEAD@{1} : 해당 HEAD@{1}로 커밋을 돌아가는 명령어
- git reset --mixed 고유번호 : 지정한 커밋 시점으로 돌아가면서, 코드는 그대로 남겨두고 git add 했던 상태(스테이징)만 취소하는 명령어
- git branch feature/login : feature/login 이라는 브랜치를 만드는 명령어
- git checkout feature/login : feature/login이라는 이름의 브랜치로 이동(Switch)한다"는 뜻
- git branch --delete feature/login : 내 컴퓨터(로컬)에 있는 feature/login 브랜치를 안전하게 삭제하는 명령어 (이미 병합이 끝난 브랜치를 정리할 때 사용)
- git branch --list : 현재 내 컴퓨터에 존재하는 브랜치들의 목록을 보여주고, 현재 내가 어떤 브랜치에 위치해 있는지(*) 표시해줌
- git checkout -b feature/login : feature/login 브랜치를 새로 만듦과 동시에 그 브랜치로 곧바로 이동해 주는 단축 명령어
- git merge feature/login : merge를 메인에 합친다는 뜻
- -D : 강제로 지우는 명령어
