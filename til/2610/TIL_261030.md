### <터미널 명령어>
#### <uv 설치 과정>
    winget search uv
    winget install uv
    exit
    프로젝트를 위한 폴더를 만든 이후
    uv init --no-package : uv 패키지
    cat .python-version : python-version 파일 확인 명령어
    uv run 파일명.확장명 : 해당 파일의 코드를 실행
    uv sync : 프로젝트 진행하면서 간혹 파일중에 내용이 같아야 하는 부분이 다를 때 동기화하는 명령어
    uv python pin : 프로젝트 별로 python 버전이 달라야 하는 상황을 대비해서 명령어로 폴더 내에 파이썬 버전을  3.12로 고정시킴
    uv.lock 파일에 uv add fastapi 입력 후 설치 (uv.lock 파일에 fastapi 패키지 설치)
    uv tree --depth 1 (uv tree이 방법도 있음)
    uv remove fastapi : 패키지 삭제 방법
    후에 uv sync 입력
    가상환경 연결 시엔 which python 입력 후
    가상환경 연결 해제시엔 deactivate 입력 후 whcih python 입력으로 가상환경 연결해제 유무 확인 가능

    uv add ipykernel : 주피터 노트북이나 VSCode에서 내 프로젝트의 가상환경(.venv)을 인식하고 코드를 실행할 수 있게 만들어 주는 연결 다리(ipykernel)를 설치하고 기록하는 명령어
