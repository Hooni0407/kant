### <터미널 bash 명령어>
- rm -rf 파일명 : 해당 파일을 삭제함 (rf : 하위파일까지 모두 영구삭제)
- git config --list : 내 컴퓨터에 설정된 GIT 설정 리스트를 보여줌
- git config --global user.email "이메일 주소" : global 설정에 user.email 값을 "이메일 주소"로 추가하겠다는 뜻. (값을 추가 하지 않은 상태에선 none이며 list 출력시 보여주지 않음)
- git config --global --unset user.email : 현재 등록되어 있는 user.email 설정을 삭제(초기화) 함
- git config --global user.name "이름" : global 설정에 user.name 값을 "이름"으로 추가하겠다는 뜻. (값을 추가 하지 않은 상태에선 none이며 list 출력시 보여주지 않음)
- git status : 현재 작업 중인 파일들의 상태를 확인함
- git add README.md(파일명) : 지정한 (파일명)만 골라서 다음 저장(commit)을 위해 대기 상태(Staging Area)로 올림
- git commit (ex : git commit -m "feat: Add README.md") : 해당 메세지를 커밋하겠다 라는 뜻.
    - -m : 커밋메세지도 같이 저장한다는 뜻
    - working tree : 현재 작업중이던 파일을 커밋한 위치 (ex : working tree main 이렇게 적혀 있다면 main 이란 곳에 커밋이 되었다는 뜻)
- git log : 지금까지 만들어진 커밋 이력을 시간순으로 보여줌
- w : 저장
- wq : 저장 후 exit
    - ! : 강제성 명령어(명령어 앞에 붙임)
- git add . : 현재 작업중이던 파일을 Staging Area로 올림
- git log --oneline : git log 명령어보다 좀 더 간략하게 출력해줌(명령어 하나씩만 출력해줌)
    - 한줄씩 출력
- git log --oneline --all : HEAD 상관없이 모든 커밋을 보여줌
- git checkout 고유번호 : 해당 고유번호의 커밋으로 돌아가는 명령어
- git reset --hard : 현재 내 컴퓨터에서 작업 중이던 모든 변경 사항(파일 수정, 추가 등)을 싹 무시하고, 가장 최근에 저장했던 상태(HEAD)로 완전히 되돌아가라라는 뜻
- git checkout main : 다른 branch나 임시 상태에서 기본 main branch로 이동(전환)하는 명령어
- git remote add origin (주소)(ex:https://github.com/Hooni0407/kant.git) : 매번 명령어로 다 치려면 번거롭기 때문에, "이 긴 주소를 앞으로 origin이라고 부르겠다!" 하고 내 컴퓨터에 등록해 주는 별명
- git remote -v : 내 컴퓨터의 프로젝트(폴더)가 어떤 온라인 깃허브 저장소와 연결되어 있는지 그 주소 목록을 자세히 보여주는 명령어
    - fetch 내 컴퓨터가 깃허브(원격 저장소)에 있는 최신 소스를 다운로드(가져오기)할 때 사용하는 주소
    - push 보안상의 이유로 더 안전한 링크 (실습중엔 굳이 서로 주소를 다르게 할 필요가 없기 때문에 fetch랑 push 주소가 같다고 뜸)
- git push origin main : 내 컴퓨터 안의 Git에게 앞으로 origin이라는 이름표를 붙일 주소는 이거야. 기억해 둬!하고 연락처(주소록)를 저장해 둔 것
- --- : 화면 상에 가로로 쫙 그어지는 '구분선(Horizontal Rule)'을 만드는 문법

### <GITHUB PUSH 순서>
1. 폴더 생성 (mkdir 파일명)
2. 해당 폴더로 먼저 들어감 (cd 파일명)
3. 해당 폴더에 만들 파일 생성 (touch 파일명.확장명)
4. ls로 상태 확인 (잘못 만들었을 땐 rm -rf 파일명.확장명 입력으로 삭제)
5. 해당 폴더를 "이제부터 Git으로 관리하겠다"라고 지정하는 최초 1회 실행 명령어 (git init)
6. 파일 완성 후 Staging Area에 add 시키기 (git add .) (주의사항:폴더안에 폴더에 들어가서 파일을 커밋하면 안됨 폴더 전체를 커밋 해야하게 때문에, 아니면 에러남)
7. 파일의 대한 메시지도 커밋해야함 (git commimt -m "메세지")
8. 내 컴퓨터 저장소와 깃허브(원격) 저장소를 연결해 주는 명령어 (git remote add origin 깃허브주소)
7. GITHUB로 PUSH한다. (git push origin main) (main에 origin이란 링크로 push 하겠다는 뜻)

### <부가 설명>
    - markdown : 파일 생성할 때 한글이 포함되어있으면 에러남
    -  Untracked : 추적되지 않음 초록색으로 u자 표시됨
        - A : add 추가가 됐단 뜻
        - M : 이전에 한번 커밋된 파일이 수정되었다는 뜻
        - U : untracked 커밋되지 않은 새로운 파일이란 뜻
    -  pull : fetch, 머지 기능을 둘다 한번에 사용 해주는 업로드용
